# Show HN: REAP - Zero-knowledge asset distribution protocol built on Midnight Network Compact contracts.

## Summary
Zero-knowledge asset distribution protocol built on Midnight Network Compact contracts.

## Architecture and Design
Midnight Network Compact language, TypeScript, React, and cryptographic ZK circuits.

## Core Features
- Private ownership verification without disclosing account balances.
- Verifiable zero-knowledge proofs for compliant asset claims.
- Compact smart contracts deployed to Midnight Network testnet.
- Web3 browser wallet integration for seamless private transactions.
